# For You ♡ — Birthday Website

A responsive birthday love-letter website made with plain HTML, CSS, and JavaScript. It uses only the six photos supplied in the uploaded ZIP (one featured image and five gallery images).

## Run it

Open `index.html` in a modern browser. No build step or package installation is needed. For best results, use a local static server or deploy the folder to GitHub Pages, Netlify, or Vercel.

## Personalize it

- Edit the birthday wording and story directly in `index.html`.
- Replace the six images in `assets/` while keeping the same filenames, or update their paths in the HTML.
- Birthday wishes are stored in the visitor's browser using `localStorage`; they are not shared between devices or visitors. A shared guestbook needs a backend or hosted database.
- Google Fonts are used for typography when internet access is available; fallback fonts are included.
